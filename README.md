# Oral Health AI Research

MSc dissertation opportunities in oral health AI with Prof. Paulo Vitor de Campos Souza, NOVA IMS.

## Website

https://pdecampossouza.github.io/OralHealth-AI-Research/

The website presents five research directions, a synthetic interactive detection and segmentation demonstration, research starter resources, and contact information.

## Publishing and maintenance

This is a static HTML, CSS and JavaScript website. GitHub Pages serves the `main` branch from the repository root. No build or package installation is required. The five optimized WebP illustrations are embedded in `index.html`, so the published page is self-contained.

The five WebP illustrations are conceptual AI-generated artwork. They are not patient photographs or validated clinical results. Dataset access and image reuse conditions are documented in the research repositories.
